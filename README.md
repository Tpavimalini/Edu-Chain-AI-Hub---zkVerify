# Edu-Chain-AI-Hub---zkVerify
Edu Chain AI Hub transforms education by integrating AI-generated assessments with blockchain verification. Educators can submit AI-powered assessments, ensuring authenticity and accuracy through zkVerify proofs.


Overview:
Edu Chain AI Hub is a Web3 decentralized application (dApp) that integrates AI-powered educational assessments with the EDU Chain blockchain and zkVerify proofs. The project aims to ensure the authenticity, verifiability, and decentralization of educational assessments and research submissions.

Features:
AI Model Verification: Track which AI models generated the content.
Skill Mapping: Tag assessments with relevant skills.
Difficulty Levels: Rate content complexity.
zkVerify Integration: Ensure assessment authenticity.
IPFS Storage: Store assessment content securely.
Wallet Connection: Supports transactions and authentication.

Problem It Solves:
Traditional educational assessments lack verifiability and decentralized authentication. Edu Chain AI Hub addresses these issues by leveraging zkVerify for proof verification and the EDU Chain blockchain to store validated educational data securely.

Technologies Used:
Solidity (Smart Contracts)
React.js (Frontend)
Wagmi (Wallet Integration)
zkVerify (Proof Verification)
EDU Chain (Blockchain Infrastructure)
IPFS (Decentralized Storage)
Installation & Setup

Clone the repository:
git clone https://github.com/your-username/edu-chain-ai-hub.git
cd edu-chain-ai-hub

Install dependencies:
npm install

Start the development server:
npm run dev

Deploy smart contract:
Update the contract details in src/contracts/EduAIVerifier.sol

Deploy it to EDU Chain

Update the CONTRACT_ADDRESS in src/components/ResearchSubmission.tsx
